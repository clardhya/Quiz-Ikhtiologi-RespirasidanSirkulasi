HOW TO USE
================================================================================

1. ANSWER QUESTIONS
   - Type your answer in the text field
   - Answers auto-save as you type
   - Character count shown below field

2. NAVIGATE
   - Click any number in the left grid to jump
   - Use Previous/Next buttons to navigate sequentially
   - Current question highlighted in cyan

3. TRACK PROGRESS
   - Green = Answered
   - Gray = Unanswered
   - Cyan = Currently viewing

4. SUBMIT
   - Click "Submit Quiz" button (available anytime)
   - Goes to results page

5. REVIEW RESULTS
   - See total score and percentage
   - Review all questions with answers
   - View explanations (Pembahasan)
   - Click "Retake Quiz" to start over

================================================================================
ANSWER MATCHING
================================================================================

Answers are:
- Case-insensitive (RESPIRASI = respirasi = Respirasi)
- Whitespace trimmed ("  respirasi  " = "respirasi")
- Support multiple variations (see quizData.ts)

Example from Q1:
  Accepted: "respirasi", "proses respirasi"
  All match: "RESPIRASI", "  respirasi  ", "Proses Respirasi", etc.

================================================================================
TROUBLESHOOTING
================================================================================

"npm: command not found"
  → Install Node.js from https://nodejs.org/
  → Verify: node --version

"Port 3000 already in use"
  → npm run dev -- -p 3001

"Module not found" errors
  → rm -r node_modules package-lock.json
  → npm install

PowerShell execution policy error
  → Use Command Prompt (cmd) instead
  → Or use QUICK_START.bat script

Changes not showing
  → Hard refresh: Ctrl+F5 (Windows) or Cmd+Shift+R (Mac)
